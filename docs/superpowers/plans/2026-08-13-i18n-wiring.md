# i18n Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire internationalization (i18n) throughout the entire Hacienda Mobile app, enabling multi-language support with English as the base language and French as the second language.

**Architecture:** Use `i18next` with `react-i18next` for React Native, leveraging `react-native-localize` for device language detection. Translation files will be structured by feature/screen with JSON format. The existing dayjs locale setup in `src/utils/device.ts` will be integrated with the new i18n system.

**Tech Stack:** i18next, react-i18next, react-native-localize, TypeScript

## Global Constraints

- Node.js >= 18
- React Native 0.76.3
- TypeScript 5.0.4
- NativeWind for styling (no changes needed)
- MobX for state management (stores may need translation access)
- Maintain existing code style and patterns
- English is the base/fallback language
- French is the second supported language
- All translations must support dynamic variables where needed
- Date/time formatting leverages existing dayjs locale setup

- [ ] **Step 2: Create i18n configuration**

Create `src/i18n/index.ts`:

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import * as RNLocalize from 'react-native-localize';

import en from './locales/en';
import fr from './locales/fr';

const resources = {
  en: { translation: en },
  fr: { translation: fr },
};

const getDeviceLanguage = (): string => {
  try {
    const locales = RNLocalize.getLocales();
    if (locales.length > 0) {
      const languageCode = locales[0].languageCode;
      // Check if we support this language, fallback to English
      return languageCode in resources ? languageCode : 'en';
    }
  } catch (error) {
    console.warn('Failed to detect device language:', error);
  }
  return 'en';
};

i18n.use(initReactI18next).init({
  resources,
  lng: getDeviceLanguage(),
  fallbackLng: 'en',
  interpolation: {
    escapeValue: false, // React already escapes
  },
  react: {
    useSuspense: false,
  },
});

export const changeLanguage = (language: string) => {
  i18n.changeLanguage(language);
};

export const getCurrentLanguage = (): string => {
  return i18n.language;
};

export default i18n;
```

import { View, Text, TouchableOpacity } from 'react-native';

import { changeLanguage, getCurrentLanguage } from '@/i18n';

const languages = [
  { code: 'en', name: 'English' },
  { code: 'fr', name: 'Français' },
];

export default function LanguageSettings() {

  const currentLanguage = getCurrentLanguage();

  };

      <Text className="text-sm text-gray-500 mb-4">{t('language.subtitle')}</Text>
      
      {languages.map((lang) => (
        <TouchableOpacity
          key={lang.code}
          onPress={() => handleLanguageChange(lang.code)}
          className={`p-3 rounded-lg mb-2 ${
            currentLanguage === lang.code ? 'bg-blue-500' : 'bg-gray-200'
          }`}>
          <Text className={currentLanguage === lang.code ? 'text-white' : 'text-black'}>
            {lang.name}
          </Text>
        </TouchableOpacity>
      ))}
    </View>
  );
}
